# Nova Space

Навчальний проект на тему "Архітектурне бюро «Новий Простір» («Nova Space»)". Є сайтом-лендингом для бізнесу "Nova Space"

## Посилання

- Netlify: https://lab6-lopashchenko.netlify.app/

## Технології

- HTML5
- CSS, Tailwind CSS
- Git, Github
- Netlify

## Структура

- `index.html` - головна сторінка
- `css/` - CSS стилі
- `assets/` - використані ресурси

## Локальний запуск

1. Клонувати репозиторій: `git clone https://github.com/al1va/weblabs-novaspace.git`
2. Відкрити файл `index.html` у браузері, або через Live Server.
